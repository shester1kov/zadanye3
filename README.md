# Задание 3. Проект "Каталог товаров"

## Выполнил Шестериков Дмитрий

Этот проект состоит из двух серверов:

1. **Admin сервер** - предоставляет API для управления продуктами.
2. **User сервер** - отображает каталог продуктов в веб-интерфейсе.

## Требования

Перед началом убедитесь, что у вас установлены:

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/)

## Установка

1. Клонируйте репозиторий или скопируйте файлы проекта.
2. Перейдите в папку проекта.

### Установка зависимостей для Admin сервера

```bash
cd ./zadanye3/admin
npm install
```

### Установка зависимостей для User сервера

```bash
cd ../user
npm install
```

## Запуск серверов

### Запуск Admin сервера

1. Перейдите в папку `admin`:

```bash
cd ../admin
```

2. Запустите сервер:

```bash
node server.js
```

3. Сервер будет доступен по адресу: <http://localhost:3000>.

### Запуск User сервера

1. Перейдите в папку user в новом терминале:

```bash
cd ./zadanye3/user
```

2. Запустите сервер:

```bash
node server.js
```

3. Сервер будет доступен по адресу: <http://localhost:8080>.

## Использование

### Admin сервер

Admin сервер предоставляет API для управления продуктами. Вы можете использовать Swagger UI для тестирования API и в качестве админ панели. <http://localhost:3000/api-docs>

### User сервер

User сервер отображает каталог продуктов. Откройте <http://localhost:8080> в браузере, чтобы увидеть список продуктов.

## Структура проекта

zadanye3/
